# Project

## Purpose

This repository contains the public website for Evoke Creative Creations, a portfolio site for a brand designer and game UI designer. The site presents services, selected work, testimonials, blog content, and contact information.

## Current Technology

Known facts from the repository:
- The site is currently a static HTML website.
- Content is delivered through standalone HTML files.
- Inline CSS is used in each page.
- Inline JavaScript is used in each page for interactive behaviors and page-level scripts.
- No separate CSS or JavaScript asset files are visible in the repository root.
- External dependencies include Google Fonts and remote canonical/meta URLs.

## Current State

The website appears to be a completed static portfolio experience with many pages and a consistent visual language. This documentation audit is a documentation-only update and does not change the website implementation.
