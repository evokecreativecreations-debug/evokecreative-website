# Design System

## Overview

This design system is inferred from the current HTML files and their inline CSS. It is not a new system; it documents what already exists.

## Fonts

Observed typography stack:
- Heading style: Bricolage Grotesque.
- Body style: Plus Jakarta Sans.
- Monospaced labels and code-like accents: Space Mono.

## Colors

Observed color tokens from the shared CSS variables:
- Ink / background: #0E0E14, #15121F, #1B1628
- Text: #E4DFF2
- Violet accent: #6C3FE8
- Pink accent: #FF5F87
- Light text / lavender: #EDE7FB
- Muted text: #A79FC7
- White / high contrast: #FFFFFF

## Typography Patterns

Common patterns visible across the pages:
- Large bold hero headings with tight letter spacing.
- Monospaced eyebrow labels and section labels.
- High-contrast body copy with generous line-height.
- Emphasis using gradient text and accent color.

## Buttons and Actions

Observed button styles:
- Primary buttons with violet fill and rounded pill shape.
- Outline buttons with light border and transparent background.
- Light buttons with pink accent fill.
- Buttons commonly transition on hover with subtle lift and color changes.

## Spacing and Layout

Observed patterns:
- Content sections use generous horizontal padding around a 6vw container.
- Cards and panels use rounded corners and subtle borders.
- Grid layouts are used for services, portfolio features, stats, and the about section.
- The layout favors a dark, spacious, editorial feel rather than a minimal flat interface.

## Visual Style Patterns

Observed recurring UI patterns:
- Dark gradient background with soft mesh/glow overlays.
- Glassy translucent nav bars with blur.
- Rounded cards with border and hover elevation.
- Portfolio thumbnails with dark overlays and hover reveal text.
- Marquee-style highlight strips and CTA bands.
- Custom cursor and animated reveal effects.
